# 视觉设计工作流

## 最小设计 Brief

```markdown
- 目标：
- 受众：
- 渠道与尺寸：
- 必须出现的信息：
- 品牌素材/配色：
- 禁用项：
- 交付：PNG/JPG/可编辑源文件（待确认）
```

## 执行与检查

1. 先确定内容层级，再选择构图和视觉方向。
2. 精确中文、日期、价格、二维码与 Logo 必须回读原件；生成图片中的文字不作为最终事实依据。
3. Brief 已明确 PNG 像素尺寸时，生成后运行 Plugin 根目录的尺寸检查脚本：

   ```bash
   python3 scripts/check_image_dimensions.py <视觉成品.png> --width <期望宽度> --height <期望高度>
   ```

   检查失败时不得把图片称为已验收；先重新生成、裁切或请用户确认是否接受不同尺寸，再按实际目标重跑。
4. 实际打开图片，检查主要内容是否被裁切、重要元素与边缘的间距，以及缩小后的可读性。脚本通过只证明 PNG 像素尺寸正确，不代表构图、文案或授权已验收。

## 课堂示例

输入：一次线下活动的受众、主题、渠道尺寸和已授权 Logo。

最小成果：一张无易错长文本的活动主视觉、对应生成提示词和可放入编辑器的准确标题文案。
